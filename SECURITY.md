# 🔐 Security Policy

## AZ: Frontier Zero

Thank you for helping keep **AZ: Frontier Zero** safe and reliable.

**AZ: Frontier Zero** is a low-poly 3D third-person shooter developed using **Unity and C#**, with a focus on modular gameplay systems, combat mechanics, and cross-platform development.

Security issues, vulnerabilities, and other potentially harmful problems are welcome for responsible reporting.

---

## 📌 Supported Versions

AZ: Frontier Zero **currently has no officially supported versions or releases**.

The project is actively under development, and security-related issues will be reviewed based on their severity and impact.

---

## 🚨 Reporting a Security Problem

Please report security problems **directly to the project maintainer** rather than publicly posting sensitive details.

When submitting a report, provide as much relevant information as possible so the issue can be properly investigated.

### Please include:

* **Issue title**
* **Detailed description of the problem**
* **Steps to reproduce**
* **Expected behavior**
* **Actual behavior**
* **Affected Unity version or project version**
* **Affected platform**
* **Affected file, script, system, or component**
* **Error messages or logs**
* **Screenshots or screen recordings**
* **Proof of concept**, when applicable
* **Potential impact**
* **Suggested fix**, if you have one

Providing complete and accurate information helps make investigation and resolution faster.

---

## 🔒 Do Not Publicly Share Sensitive Information

Please do not include the following in public issues, discussions, commits, or other public channels:

* Passwords
* API keys
* Authentication tokens
* Private credentials
* Private keys
* Personal information
* Sensitive configuration data
* Private signing certificates or keystores
* Any other confidential information

If a credential is accidentally exposed, revoke or rotate it immediately.

---

## 🛡️ Responsible Disclosure

When reporting a security vulnerability:

* Do not intentionally damage the project or infrastructure.
* Do not access or modify data that does not belong to you.
* Do not disrupt development systems or services.
* Do not use vulnerabilities for malicious purposes.
* Do not distribute malicious code or modified project files.
* Provide enough technical information to reproduce and understand the problem.

Please allow the maintainer reasonable time to investigate the reported issue before publicly disclosing detailed technical information.

---

## 🧩 Third-Party Components

AZ: Frontier Zero may use third-party:

* Unity packages
* Assets and asset-store content
* Models and textures
* Audio files
* Plugins
* Libraries
* Input and animation systems
* Development tools

Problems originating from third-party components may also be reported, especially when they could affect the security, stability, or integrity of the project.

Please include the affected component and its version whenever possible.

---

## 🎮 Game and Platform Security

Security reports may cover issues affecting:

* Player movement and gameplay systems
* Weapon handling and damage systems
* Enemy AI and combat mechanics
* Save data and configuration files
* Unity project files and dependencies
* Windows, macOS, and Linux builds
* Android and iOS builds
* Build configurations and release artifacts
* GitHub repository access and automation

The project is currently focused on single-player gameplay. Features and platforms that have not yet been implemented are not considered released or officially supported.

---

## 🐛 General Bugs and Development Issues

Normal gameplay bugs, visual problems, feature requests, performance issues, animation problems, and development suggestions do **not** need to be reported as security vulnerabilities.

These can be submitted through the repository's normal **GitHub Issues** system.

For any reported problem, please provide **clear reproduction steps and relevant technical details**.
